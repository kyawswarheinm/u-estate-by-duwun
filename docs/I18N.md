# UI languages and reference currencies (T18)

The UI uses `en`, `th`, `ar`, `zh-Hant` and `es`. English is the source dictionary in `src/i18n/en.ts`. All other dictionaries satisfy its mapped `Dictionary` type. They are marked `review: machine-translated`; native review is still needed, starting with Thai.

`getPreferences()` resolves the locale cookie, then the signed-in profile's locale, then English. The root layout renders `lang` and `dir` on the server and supplies the same preferences to client components. Existing URLs stay unchanged. The language/currency form saves one-year, HttpOnly, SameSite=Lax cookies (Secure in production). For signed-in users it updates only the server-resolved owner's profile. Saving a preferred language in Account settings also updates the locale cookie.

Use `getTranslations()` in server components, `useI18n()` in client components, or `<Text message="…" values={{ name }} />` for typed UI text. Placeholder values are plain strings/numbers rendered by React, never HTML. `<Label>` translates known system labels and retains unknown source text; it is intended for existing validation/status outputs. New static UI copy should use typed `Text` or `t` keys rather than relying on that fallback.

Core navigation, listing/offer/co-buy headings and actions, form labels, common validation messages, account screens and footer use the dictionaries. User-authored property names, locations, original documents and existing computed narrative text remain source content. Live AI/content translation is a separate feature. Partner component copy and restyling remain T33; their initial AI/voice language now follows the page locale.

CSS uses logical alignment and spacing. Arabic changes document direction; property titles are isolated with `bdi`. Charts keep their chronological axis left to right. Grid children can shrink so wide tables scroll inside their own containers at 360px instead of widening the page. Arabic and Traditional Chinese have self-hosted Next font families alongside the existing Thai font.

`Money` always shows the authoritative THB amount. USD, EUR and CNY are optional approximate reference amounts, calculated with a fixed **2025-01-02 historical snapshot**, with its date shown next to each conversion. These are not current quotes. The source is recorded in `src/i18n/index.ts`; refreshing rates must update both the numbers and date from a verifiable source. Currency selection never changes an input amount, valuation, offer, fee, wallet balance or business rule. Locale formatting uses Latin digits; dates use Asia/Bangkok.
