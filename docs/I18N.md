# UI languages and reference currencies (T18)

The UI uses `en`, `th`, `ar`, `zh-Hant` and `es`. English is the source dictionary in `src/i18n/en.ts`. All other dictionaries satisfy its mapped `Dictionary` type. They are marked `review: machine-translated`; native review is still needed, starting with Thai.

`getPreferences()` resolves the locale cookie, then the signed-in profile's locale, then English. The root layout renders `lang` and `dir` on the server and supplies the same preferences to client components. Existing URLs stay unchanged. The language/currency form saves one-year, HttpOnly, SameSite=Lax cookies (Secure in production). For signed-in users it updates only the server-resolved owner's profile. Saving a preferred language in Account settings also updates the locale cookie.

Use `getTranslations()` in server components, `useI18n()` in client components, or `<Text message="…" values={{ name }} />` for typed UI text. Placeholder values are plain strings/numbers rendered by React, never HTML. `<Label>` translates known system labels and retains unknown source text; it is intended for existing validation/status outputs. New static UI copy should use typed `Text` or `t` keys rather than relying on that fallback.

Core navigation, listing/offer/co-buy headings and actions, form labels, common validation messages, account screens and footer use the dictionaries. User-authored property names, locations, original documents and existing computed narrative text remain source content. Live AI/content translation is a separate feature. Partner component copy and restyling remain T33; their initial AI/voice language now follows the page locale.

CSS uses logical alignment and spacing. Arabic changes document direction; property titles are isolated with `bdi`. Charts keep their chronological axis left to right. Grid children can shrink so wide tables scroll inside their own containers at 360px instead of widening the page. Arabic and Traditional Chinese have self-hosted Next font families alongside the existing Thai font.

`Money` and `formatMoneyRef()` always show the authoritative THB amount first. USD, EUR and CNY are optional approximate references ("฿4,000,000 (≈ €106,400)"), calculated with a fixed, dated **ECB reference-rate snapshot of 2026-10-15** (previously 2025-01-02), whose date is shown in the currency menu and next to `Money` conversions. These are not current quotes. The source URL is recorded in `src/i18n/index.ts`; refreshing rates must update both the numbers and date from a verifiable source. Never format a price directly in another currency: use `formatMoneyRef` (strings) or `<Money>` (blocks). Currency selection never changes an input amount, valuation, offer, fee, wallet balance or business rule. Locale formatting uses Latin digits; dates use Asia/Bangkok. Reference strings are wrapped in a first-strong isolate (U+2068…U+2069) so they stay one unit inside Arabic sentences.

## Preference menus (16 Oct 2026)

`src/components/preferences/`: `OptionMenu` is the shared accessible menu (button + listbox, arrow keys, Home/End, type-ahead on any word, Enter/Space, Escape closes only the menu, focus returns to the trigger, "Current" badge on the selection). `PreferenceMenus` builds the three menus:

- **Language:** a language-code chip, never a flag (languages are not countries); native name plus the name in the current UI language (`Intl.DisplayNames`).
- **Currency:** the issuer's flag (inline SVG, because Windows shows emoji flags as letters; the euro uses the EU flag), localized name (`Intl.DisplayNames`), code and symbol, and a footer stating that prices are in THB and other currencies are dated ECB references.
- **Theme:** System, Light, Dark (see [THEME.md](THEME.md)).

Language and currency save through `savePreferences` (cookies plus the signed-in profile), so every page re-renders. Sentences that need a link or bold text inside use `withSlot()` from `src/i18n/slot.tsx` rather than splitting sentences into fragments.

UI copy that used to be hard-coded (voice search, explain, chat, ledger fingerprint, partners, sign-up, offer room, risk checklist, map controls, account pages) now goes through the dictionaries. Remaining English on translated pages is data, not UI: demo persona names, stored ledger entries, seed appraisal sources, deed-type names, and the stats method note from the data pipeline.
