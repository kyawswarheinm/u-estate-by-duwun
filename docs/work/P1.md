### Proposed places schema for P3 (outside the frozen contract)

No change to `types.ts`, `index.ts`, `contract.test.ts`, analytics, npm manifests or existing UI/tool imports. P3/integrator must agree before wiring this file at merge.

```ts
type Place = {
  name: string;                         // public mapped feature name; no contacts
  kind: "condo_building" | "station";
  district: string | null;             // only if addr:district is tagged; no nearest-district guess
  lat: number; lng: number;            // rounded to three decimals, Bangkok/vicinity bbox
  osm_id: string;                      // node/<id>, way/<id>, or relation/<id>
  source: "OpenStreetMap";
  fetched_at: string;                  // ISO timestamp, preserved on HTTP-cache replay
};
type PlacesFile = {
  meta: {
    source: "OpenStreetMap";
    attribution: "© OpenStreetMap contributors, ODbL 1.0";
    license: "ODbL-1.0"; license_url: string;
    endpoint: string;
    method: "overpass" | "regional_extract_fallback";
    extract_url: string | null;          // resolved dated extract URL
    extract_date: string | null;         // source HTTP Last-Modified, not export date
    extract_sha256: string | null;
    extract_last_modified: string | null;
    bbox: [number, number, number, number]; // south, west, north, east
    fetched_at: string;
    note: string;
  };
  places: Place[];
};
```

**Limits for P3:** these are mapped places, not checked listings or proof of condo ownership/classification. `condo_building` also covers named residential areas because the requested kind union has no residential-area variant. Station classification uses rail/public-transport tags plus metro/light-rail or BTS/MRT/ARL operator/network evidence. Regional-extract way positions use polygon area centroids (line-length centroids for open/degenerate geometries); relation features are omitted by the regional-extract fallback. Coverage is a bounded snapshot, not a complete inventory. Never join SYNTHETIC prices to a real named building. Any “near BTS” match on the synthetic listing snapshot means a district reference point, not an actual condo near that station. Preserve ODbL attribution/licensing when showing or redistributing the places.
